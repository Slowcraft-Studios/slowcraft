# Slowcraft

Воксельная игра, которая никуда не торопится. Обновления выходят очень маленькими: иногда это одна новая надпись на экране паузы.

**Как поиграть:** скачай архив игры, распакуй и запусти `Slowcraft.exe`. Лаунчер сам скачает новые версии, вручную отсюда ничего брать не нужно.

Все версии остаются в лаунчере навсегда: можно запустить хоть самую первую, где была только платформа 5×5.

Здесь, в [Releases](https://github.com/Slowcraft-Studios/slowcraft/releases), лежат файлы, которые скачивает лаунчер.
