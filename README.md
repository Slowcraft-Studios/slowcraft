# Slowcraft

Воксельная игра, которая никуда не торопится. Обновления выходят очень маленькими: иногда это одна новая надпись на экране паузы.

### 👉 [Скачать Slowcraft для Windows (Slowcraft-windows.zip)](https://github.com/Slowcraft-Studios/slowcraft/releases/latest/download/Slowcraft-windows.zip)

**Как запустить:**
1. Скачай **[Slowcraft-windows.zip](https://github.com/Slowcraft-Studios/slowcraft/releases/latest/download/Slowcraft-windows.zip)** (или открой [страницу релиза](https://github.com/Slowcraft-Studios/slowcraft/releases/latest)).
2. **Обязательно распакуй архив** целиком в любую папку (правой кнопкой → «Извлечь всё…», например на рабочий стол или в «Документы»). Прямо из нераспакованного архива игра не запустится.
3. Запусти **`Slowcraft.exe`** внутри распакованной папки `Slowcraft`.
4. Если Windows покажет синее окно SmartScreen («Windows защитила ваш компьютер») — нажми **«Подробнее»** → **«Выполнить в любом случае»**.

Java и все библиотеки уже внутри архива, ничего отдельно ставить не нужно. Лаунчер сам докачивает новые версии при запуске — качать отдельные `game.jar` из технических релизов версий не надо.

Все версии остаются в лаунчере навсегда: можно запустить хоть самую первую `0.0.1`, где была только платформа 5×5.
